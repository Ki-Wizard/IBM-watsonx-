# 가막만 적조 안내 갱신 시연

## 범위

- 수협 당직자 한 명이 가막만의 직전 승인 안내를 계속 사용할 수 있는지 확인합니다.
- 공식 발표와 가상의 수협 승인본을 사용합니다. 최종 승인과 실제 발송은 담당자 업무로 둡니다.
- IBM watsonx Orchestrate 에이전트 한 개와 모의 승인함을 연결합니다. 연결이 막히면 같은 자료와 승인함을 사용하는 로컬 재현 경로를 표시합니다.

## 팀 작업과 연결 지점

| 담당 | 첫 산출물 |
| --- | --- |
| PM·백엔드 | 공통 예시 JSON, 공식 자료 조회, 결과 검증, 승인함 저장 |
| 화면·앱 | 예시 JSON으로 구현한 입력·판정·근거·승인함 화면 |
| 프롬프팅 | 공식 근거 사용 규칙과 사례별 기대 결과 |
| AI 엔지니어링 | 단일 에이전트, 근거 조회 도구, 실제 호출 기록 |

입력은 해역, 기준시각(KST), 직전 승인본 ID, 질문입니다. 결과에는 판정, 해역 특보와 정부 위기경보의 변경, 근거 ID, 승인 초안 또는 확인 질문, 장부 상태, 실행 모드를 포함합니다.

조회는 기준시각까지 확인 가능한 자료로 제한합니다. 해역·승인본·공식 근거 판본이 같은 요청은 기존 초안을 반환합니다. 공식 근거가 부족하거나 조회가 실패하면 `확인 필요`로 기록합니다.

## 검증 사례

| 사례 | 기대 결과 |
| --- | --- |
| 2025-08-29 16:30 KST | `갱신 필요`. 가막만 적조주의보와 정부 위기경보 경계를 구분해 표시하고 초안 1건을 등록합니다. |
| 8월 26일 가상 승인 직후 | `유지`. 29일 발표를 제외하고 확인 이력만 남깁니다. |
| 동일 요청 반복 | 기존 초안 ID를 반환하고 승인함 건수를 유지합니다. |
| 일부 해역 해제 범위 불명 | 상세 근거를 조회한 뒤에도 불명확하면 `확인 필요`와 확인 질문을 남깁니다. |
| 당시 수온 누락 | 수온에는 `확인 필요`를 표시하고 확인된 특보 변경은 초안에 반영합니다. |
