# 가막만 시연 검증 기록

## IBM 교육 계정

2026년 11월 20일(KST) 실행했습니다.

| 확인 항목 | 결과 |
| --- | --- |
| 교육 계정 IAM 인증·에이전트 목록 | HTTP 200 |
| `kiw_gamak_smoke_agent` 배포 | 성공 |
| 테스트 질문과 `kiw_gamak_smoke_lookup` | 채팅 HTTP 200, 대화 이력에서 도구 응답과 검증 코드 일치 확인 |
| `kiw_gamak_red_tide` 프로젝트 에이전트 배포 | 팀 프롬프트의 핵심 원칙을 포함한 버전 배포 성공 |
| 공식 근거 도구 `kiw_gamak_official_evidence` | 대화 이력에서 실제 도구 결과 1건을 확인하고 판정·근거·실행 코드를 검증 |
| Streamlit과 SQLite 연결 | 화면에서 IBM 실호출 표시와 승인함 `0 → 1 → 1` 확인 |

두 경보와 근거 본문은 IBM 대화 이력의 공식 근거 도구 결과에서 읽습니다. 모델은 판정과 근거 ID를 반환하고, 백엔드는 도구 결과 및 로컬 공식 자료와 대조한 뒤 공통 JSON 형식과 승인함 상태를 반환합니다. 응답 검증에 실패할 경우 동일 승인함을 사용하는 로컬 재현 경로가 화면에 표시됩니다.

## 사례별 결과

팀의 질문과 기대 결과는 `examples/test-cases/`에 있습니다. 갱신, 반복 요청, 해역 불명은 같은 DB에서 실행했습니다. 다른 사례는 각각 빈 DB로 시작했습니다.

| 사례 | 실행 | 판정 | 승인함 | 확인 내용 |
| --- | --- | --- | --- | --- |
| 갱신 | IBM | 갱신 필요 | 0 → 1 | 가막만 적조주의보 14:00 및 정부 경계 16:00을 별도로 표시 |
| 유지 | IBM | 유지 | 0 → 0 | 8월 26일 17:00 기준으로 8월 29일 발표 제외 |
| 반복 요청 | IBM | 갱신 필요 | 1 → 1 | 첫 갱신 요청과 동일한 초안 ID 재사용 |
| 해역 불명 | IBM | 확인 필요 | 1 → 1 | 8월 29일 발표에 근거를 연결하고 가막만의 해제 범위를 확인 질문으로 남김 |
| 수온 누락 | IBM | 갱신 필요 | 0 → 1 | 수온은 확인 필요로 남기고 두 경보 변경을 초안에 반영 |
| 공식 자료 조회 실패 | 로컬 | 확인 필요 | 0 → 0 | 자료 파일이 없는 상황을 재현하고 확인 이력 저장 |

## 발표 순서

1. 새 SQLite 경로로 앱을 시작하고 빈 승인함을 확인합니다.
2. 가막만, 2025년 8월 29일 16:30(KST), `gamak-2025-08-26-demo`를 확인한 뒤 “이 안내를 계속 써도 되나?”를 입력해 제출합니다.
3. 두 경보와 해양수산부 원문 링크를 확인합니다. 승인 대기 초안이 1건 생성됩니다.
4. 같은 요청을 다시 제출합니다. “기존 초안 재사용”과 승인함 `1 → 1`을 확인합니다.
5. 나머지 질문은 사례별 결과 표로 설명합니다.

팀의 Streamlit 화면과 에이전트 프롬프트를 통합 브랜치에 반영했습니다. 해역 불명 질문에서 언급하는 해제는 보관된 공식 원문으로 확인되지 않아 확인 질문으로 남깁니다.

실행 방법은 [README](../README.md)를 참고하세요.
